📝 你需要输入的内容（仅3项）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开项目根目录的 .env 文件，找到以下内容并填写：

1. 关闭Mock模式：
   VITE_ENABLE_MOCK=false

2. 火山引擎API密钥：
   VITE_VOLCENGINE_API_KEY=【在这里粘贴你的API Key】

3. 火山引擎端点ID：
   VITE_VOLCENGINE_ENDPOINT_ID=【在这里粘贴你的Endpoint ID】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 如何获取这些信息？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式1: 查看详细图文教程
  📄 打开: VOLCENGINE-AI-SETUP-GUIDE.md

方式2: 快速步骤
  
  步骤1: 注册火山引擎
    网址: https://www.volcengine.com/
    
  步骤2: 开通豆包服务
    网址: https://console.volcengine.com/ark
    点击: "立即开通"
    
  步骤3: 获取API Key
    位置: API管理 -> API Key管理
    点击: "创建新的API Key"
    复制: ak-开头的密钥
    
  步骤4: 创建推理接入点
    位置: 推理接入点 -> 创建推理接入点
    配置: 
      - 名称: linping-lantern-qa
      - 模型: doubao-lite-32k (推荐)
      - 并发: 1-5
    复制: ep-开头的端点ID

✅ 配置完成后的检查步骤
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 保存 .env 文件
2. 重启开发服务器:
   - 按 Ctrl+C 停止
   - 运行 npm run dev 启动
3. 访问 http://localhost:5173/ai-qa
4. 检查页面顶部状态:
   ✅ 应该显示: 🤖 火山引擎 AI (doubao-lite-32k)
   ✅ 绿色指示灯闪烁
5. 测试提问，应该出现打字机效果
