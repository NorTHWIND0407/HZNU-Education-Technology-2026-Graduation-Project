Android APK 生成教程

当前网页项目不再直接提供 Android 安装包下载，而是保留 3 个发布包，并通过本教程说明如何利用现有 Unity 资源自行生成 APK。

推荐优先使用 rolling-lantern-source.zip。如果只是想把滚灯模块导入到你自己的 Unity 项目中，可再配合 rolling-lantern-module.unitypackage 使用。

现有可用文件

  • rolling-lantern-ar-windows.zip：Windows 展示包
  • rolling-lantern-module.unitypackage：Unity 模块复用包
  • rolling-lantern-source.zip：Unity 源工程压缩包

生成 APK 的推荐流程

  1. 先下载 rolling-lantern-source.zip 并解压。
  2. 使用 Unity Hub 打开源工程目录。
  3. 安装与工程匹配的 Unity 版本，以及 Android Build Support、Android SDK & NDK Tools、OpenJDK。
  4. 在 Unity 中进入 File > Build Settings，将平台切换到 Android。
  5. 在 Player Settings 中检查包名、版本号、最低 API、图标与权限。
  6. 确认场景已加入 Scenes In Build，并关闭 Development Build。
  7. 点击 Build，导出得到 APK 文件。

如果只拿到了 Unity 模块包怎么办

  1. 新建一个 Unity 工程。
  2. 通过 Assets > Import Package > Custom Package 导入 rolling-lantern-module.unitypackage。
  3. 自行补齐场景、AR 相机、AR Foundation 配置后，再按 Android 平台导出 APK。

这条路线可行，但工作量通常比直接使用源工程更大。

遇到常见报错时先检查

  • JDK not found：到 Unity 的 Preferences > External Tools 中启用 Unity 自带的 JDK、SDK、NDK。
  • 切不到 Android 平台：去 Unity Hub 给当前编辑器补装 Android 模块。
  • AR 真机无法运行：检查 AR Foundation、ARCore 支持、包名和最低 Android 版本设置。
